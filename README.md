# تغییر دهنده فونت صفحات وب (Font Changer Extension)

یک افزونه مدرن بر پایه **Manifest V3** سازگار با تمامی مرورگرها (**Chrome**, **Firefox**, **Edge**, **Brave**) برای تغییر سریع و یکدست فونت تمامی وب‌سایت‌ها به فونت زیبای **وزیرمتن (Vazirmatn)** و سایر فونت‌های دلخواه.

---

## ویژگی‌ها

- ⚡ **سریع و آفلاین**: فونت‌های وزیرمتن (با فرمت بهینه `woff2`) درون خود افزونه قرار دارند و بدون افت سرعت یا وابستگی به اینترنت بارگذاری می‌شوند.
- 🌐 **سازگاری کامل چندمرورگری**: پشتیبانی کامل از Chrome (Manifest V3) و Firefox (نسخه ۱۰۹ به بالا).
- 🔒 **سازگار با CSP**: هیچ درخواستی به سرورهای خارجی فرستاده نمی‌شود، بنابراین در وب‌سایت‌های حساس بانکی یا اداری با خطای Content Security Policy مواجه نمی‌شود.
- 🛡️ **حفظ آیکون‌ها و کدها**: به گونه‌ای تنظیم شده که آیکون‌ها (FontAwesome، Material Icons، SVGها) و بلوک‌های کد (`pre` و `code` در گیت‌هاب و استک‌اورفلو) به هیچ وجه به هم نریزند.
- 🎛️ **پاپ‌آپ مدیریتی کامل**:
  - فعال یا غیرفعال‌سازی سراسری با یک کلیک
  - امکان غیرفعال‌سازی برای یک دامنه یا سایت خاص
  - انتخاب بین فونت وزیرمتن با اعداد فارسی (پیش‌فرض) یا اعداد انگلیسی
  - پشتیبانی از فونت‌های سیستمی دیگر (ساحل، شبنم، تاهما) و همچنین امکان وارد کردن نام هر فونت دلخواه نصب‌شده روی سیستم
  - تنظیم فاصله بین خطوط (Line-height)
  - پیش‌نمایش زنده در خود افزونه
  - اعمال آنی تغییرات روی تب‌های باز بدون نیاز به رفرش دستی

---

## نحوه نصب در مرورگر Chrome / Edge / Brave

1. ابتدا مخزن را کلون کنید (یا فایل ZIP آن را دانلود و استخراج نمایید):
   ```bash
   git clone https://github.com/Kamandlou/font-changer.git
   ```
2. مرورگر گوگل کروم (یا هر مرورگر بر پایه Chromium مانند Edge یا Brave) را باز کنید.
3. در نوار آدرس به مسیر زیر بروید:
   ```text
   chrome://extensions
   ```
4. از گوشه بالا سمت راست، گزینه **Developer mode** را فعال کنید.
5. روی دکمه **Load unpacked** کلیک کنید.
6. پوشه پروژه کلون‌شده (`font-changer`) را انتخاب نمایید.
7. افزونه نصب شد! برای دسترسی سریع، آیکون پین (سنجاق) افزونه را در نوار ابزار بالای مرورگر فعال کنید.

---

## نحوه نصب در مرورگر Firefox

1. مرورگر فایرفاکس را باز کنید.
2. در نوار آدرس به مسیر زیر بروید:
   ```text
   about:debugging#/runtime/this-firefox
   ```
3. روی دکمه **Load Temporary Add-on...** کلیک کنید.
4. فایل `manifest.json` درون پوشه پروژه کلون‌شده را انتخاب نمایید.
5. افزونه بلافاصله در فایرفاکس فعال می‌شود!

---

## ساختار فایل‌ها

```text
font-changer/
├── manifest.json            # مانیفست افزونه (Manifest V3)
├── fonts/                   # فایل‌های فونت وزیرمتن (woff2)
├── icons/                   # آیکون‌های افزونه در سایزهای مختلف
├── popup/
│   ├── popup.html           # ساختار پاپ‌آپ تنظیمات
│   ├── popup.css            # استایل مدرن و راست‌چین
│   └── popup.js             # منطق تنظیمات و ذخیره‌سازی
└── scripts/
    └── content.js           # اسکریپت اعمال فونت روی صفحات وب
```
