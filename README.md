# تغییر دهنده فونت صفحات وب (Font Changer Chrome Extension)

یک افزونه مدرن بر پایه **Manifest V3** برای تغییر سریع و یکدست فونت تمامی وب‌سایت‌ها به فونت زیبای **وزیرمتن (Vazirmatn)** و سایر فونت‌های دلخواه.

---

## ویژگی‌ها

- ⚡ **سریع و آفلاین**: فونت‌های وزیرمتن (با فرمت بهینه `woff2`) درون خود افزونه قرار دارند و بدون افت سرعت یا وابستگی به اینترنت بارگذاری می‌شوند.
- 🔒 **سازگار با CSP**: هیچ درخواستی به سرورهای خارجی فرستاده نمی‌شود، بنابراین در وب‌سایت‌های حساس بانکی یا اداری با خطای Content Security Policy مواجه نمی‌شود.
- 🛡️ **حفظ آیکون‌ها و کدها**: به گونه‌ای تنظیم شده که آیکون‌ها (FontAwesome، Material Icons، SVGها) و بلوک‌های کد (`pre` و `code` در گیت‌هاب و استک‌اورفلو) به هیچ وجه به هم نریزند.
- 🎛️ **پاپ‌آپ مدیریتی کامل**:
  - فعال یا غیرفعال‌سازی سراسری با یک کلیک
  - امکان غیرفعال‌سازی برای یک دامنه یا سایت خاص
  - انتخاب بین فونت وزیرمتن با اعداد فارسی (پیش‌فرض) یا اعداد انگلیسی
  - پشتیبانی از فونت‌های سیستمی دیگر (ساحل، شبنم، تاهما) و همچنین امکان وارد کردن نام هر فونت دلخواه نصب‌شده روی سیستم
  - تنظیم فاصله بین خطوط (Line-height)
  - پیش‌نمایش زنده در خود افزونه
  - اعمال آنی تغییرات روی تب‌های باز بدون نیاز به رفرش دستی

---

## نحوه نصب در مرورگر Chrome / Edge / Brave

1. مرورگر گوگل کروم (یا هر مرورگر بر پایه کرومیوم) را باز کنید.
2. به آدرس زیر بروید:
   ```text
   chrome://extensions
   ```
3. از گوشه بالا سمت راست، گزینه **Developer mode** را روشن کنید.
4. روی دکمه **Load unpacked** کلیک کنید.
5. پوشه زیر را انتخاب کنید:
   ```text
   /Users/kamandlou/Projects/font-changer
   ```
6. افزونه نصب شد! برای دسترسی سریع، آیکون پین (سنجاق) افزونه را در نوار ابزار بالای کروم فعال کنید.

## ساختار فایل‌ها

```text
font-changer/
├── manifest.json            # مانیفست افزونه (Manifest V3)
├── fonts/                   # فایل‌های فونت وزیرمتن (woff2)
├── icons/                   # آیکون‌های افزونه در سایزهای مختلف
├── popup/
│   ├── popup.html           # ساختار پاپ‌آپ تنظیمات
│   ├── popup.css            # استایل مدرن و راست‌چین
│   └── popup.js             # منطق تنظیمات و ذخیره‌سازی
└── scripts/
    └── content.js           # اسکریپت اعمال فونت روی صفحات وب
```
